Model · Concept

Concept A language model does one thing: given the tokens so far, it gives a probability to every possible next token. Text is that step in a loop.

one step of generation

A decoder

The attention of this morning, with each token allowed to see only the tokens before it. Trained on one task: predict the next token of text from the web.

Probabilities

The output is a list of about 150,000 probabilities that add to 1. The model has no separate store of facts and no notion of true.

Temperature

At temperature 0 the most likely token is taken every time and the answer is repeatable. Above 0 the next token is drawn at random by probability.

RAG · Concept

Concept Retrieval-augmented generation: find the sections that bear on the question, paste them into the prompt, and let the model answer from them.

two paths: indexing and answering

Index

Split the documents into chunks and store each one so that it can be searched. Rerun when a document changes.

Retrieve

Score every chunk against the question and keep the best k. Nothing else reaches the model.

Prompt

The chunks become part of the prompt. The model weights are untouched; a policy change needs a re-index, no training.

Answer

The model reads the chunks and writes one sentence. The chunk ids travel with the answer so a person can check it.

RAG · Mechanism

Mechanism Four ways to rank the sections for a question. The next slide measures all four on the same questions.

BM25

Scores a section by the words it shares with the question, with rare words counting more. Exact on codes and product names. Blind to synonyms: "cash machine" does not match "ATM".

Dense

An embedding model turns question and section into vectors; rank by the angle between them. Matches meaning across different words. Can drift to a section on the right topic for the wrong product.

Hybrid

Run both and merge the two rankings. A section ranked high by either method ends near the top.

Reranker

A second, slower model reads the question and one section together and scores the pair. Run on the top 20 only.

hybrid: reciprocal rank fusion
score(section) = 1 / (60 + rank in BM25) + 1 / (60 + rank in dense)
Why ranks and not scores. A BM25 score and a cosine similarity are on different scales. Their ranks can be added.

Add a header

Write the document title and code at the top of every chunk before it is embedded. A chunk from the middle of a guide then still says which product it describes.

Concept Query expansion changes the question before it is searched, so that it shares words or meaning with the section that answers it.

The language model writes 3 rewordings. All 4 versions are searched and the rankings merged.

RAG · Ontology · Mechanism

Mechanism Linking finds the terms, the instance and the class that a question mentions. Each link changes the search in its own way.

two questions, three links

1. Synonyms

Every other label of a linked term joins the query. This is query expansion from a dictionary the bank controls, with no call to a model.

2. Filter

A named product or document code restricts the search to that document. A filter is a hard rule: a wrong link hides the right section.

3. Fan-out

A question about a class is searched once per instance. Top-k ranks sections by likeness to the question and has no notion of covering every product.

RAG · Expansion and ontology · Drawbacks

Drawbacks What query expansion and an ontology cost, on this knowledge base.

Someone maintains it

59 terms and 18 instances for 18 documents, written by hand. A product left out of the ontology is skipped by the fan-out, and no error is raised.

A dictionary has gaps

47 of the 89 paraphrase questions link to no term. A lookup helps where an entry exists. The model-based methods reword any question.

Labels collide

"Business card" is a label of the Business Credit Card and also an ordinary object. A wrong link followed by a filter removes the right section from the search.

Expansion by a model costs a generation. Rewording took 125 seconds and HyDE 177 seconds for 225 questions on this GPU, before any search ran.
HyDE invents figures. Its passage for the overdraft question states "$50". The passage is a search key. It must stay out of the prompt that the answering model reads.
RAG · Drawbacks

Drawbacks What this knowledge base leaves out, and what a production one has to handle.

Stale and conflicting documents

The index returns whatever is in it. Superseded versions need a status field and a filter at query time, or the model will quote the old limit with full confidence.

Permissions

Retrieval must apply the access rights of the person asking. A chunk the user may not read must never enter the prompt, because the model will repeat it.

Tables and scans

Fee tables and scanned forms lose their meaning when flattened to text. They need their own extraction step before indexing.

Cost and delay. Every question now runs an embedding model, a reranker and a prompt of several hundred tokens. On this GPU the 225 questions took 152 seconds with retrieval and 74 without.
Evaluation · Concept

Concept An LLM system is evaluated like any other model: a fixed set of inputs with known answers, run again after every change.

1. A question set

Real questions from the people who will use the system, each with the accepted answer and the document that holds it. Include questions that have no answer. A few hundred is enough to see a change of a few points.

2. A grade per answer

Three outcomes: correct, abstained, wrong. They have different costs. An abstention sends the member of staff to the document. A wrong answer sends them away with a false number.

3. A score per stage

Recall@k for retrieval, the three grades for the answer, and the abstention rate on unanswerable questions. One blended score hides which stage moved.

Here the grade is exact. Every accepted answer is a number or a short phrase, so a string match decides. Free-text answers need a person, or a model checked against a person.
The test bed for this block. Dense retrieval with a plain prompt, the retrieval pipeline with the most wrong answers: 177 correct, 16 abstained, 32 wrong out of 225. It supplies enough wrong answers to test a detector on.
Evaluation · Example

Example Three scores that compare an answer with a reference sentence. AUC is the chance that a correct answer scores above an incorrect one; 0.5 is a coin toss.

Hallucination · Concept

Concept A hallucination is an answer stated as fact that the documents do not support. In the test bed, 32 of 225 answers are wrong.

No support retrieved

The answering section was not among the top three, or does not exist. The model fills the gap with a plausible value, often a number from a neighbouring product.

Support misread

The right section is in the prompt. The model takes the wrong number from it, mixes two sections, or answers a slightly different question.

Support out of date

A superseded section is retrieved and quoted faithfully. The answer is grounded in a document and still wrong.

Unanswerable questions are the hard case. With the plain prompt the model gave a wrong answer to 53% of them, against 8% of the answerable ones.
Fluency carries no signal. The model writes a wrong answer in the same confident sentence as a right one. Detection has to come from outside the sentence.
Hallucination · Mechanism

Mechanism Four detectors that need no reference answer. Each reads the question, the retrieved context and the answer, and raises a flag.

1. Number check

Extract every number from the answer. Flag the answer if any of them is absent from the retrieved context. Ten lines of code and no model.

2. Entailment model

A small encoder trained on natural language inference reads context and answer and scores whether the first supports the second.

3. Self-consistency

Ask the same question five more times at temperature 0.8. Flag the answer if most samples give different numbers. A model that knows repeats itself.

4. Model as judge

Show the model the context, the question and the answer, and ask: is every fact in the answer stated in the context? Flag on NO.

Cost. The number check is free. The entailment model adds one small forward pass. The judge adds one generation. Self-consistency adds five.
Scoring a detector. Recall: the share of wrong answers it flags. Precision: the share of its flags that are wrong answers.

Evaluation · RAG triad · Concept

Concept Three scores, one for each link between question, context and answer. None needs a reference answer, so they can run on live traffic.

which stage each score watches

Context relevance

Does the retrieved context bear on the question? Here: the reranker’s score for the best of the three sections.

Faithfulness

Is the answer supported by the context? Here: the share of the answer’s claims that a context sentence entails.

Answer relevance

Does the answer address the question? Here: the model writes the question the answer replies to, and it is compared with the real one by embedding similarity.

Each score is a model’s opinion. On the test bed the truth is known, so each can be checked.

Prompting · Concept

Concept A prompt is a specification. Each part removes one way for the model to do something other than what was meant.

the parts, in the order they are written
Write it for a new colleague. Someone capable who has never seen the bank’s documents needs the same things: the task, the format, the definitions and one worked case.
An example outweighs a paragraph. One input with its correct output shows the format, the level of detail and the edge cases at once.

Working · Example

Example 80 fee calculations with one right answer each. Asked for the amount only, the model is right on 41%; asked to work step by step first, on 1%.

share of calculations right
one of the calculations (right answer 12)
Taking cash on a credit card costs 2.5% of the amount, with a minimum fee of GBP 3. A customer takes GBP 480 in cash. What is the fee in GBP?
What working does. The model writes one token at a time, and each intermediate result becomes input for the next token. A mistake is carried forward the same way: below, the model multiplies correctly and then adds the minimum fee.
the model’s working
To calculate the fee for taking cash on a credit card: 1. Determine the percentage fee: - The fee is 2.5% of the amount taken. - Amount taken = GBP 480 2. Calculate the fee based on the percentage: - Fee = (2.5/100) * 480 - Fee = 0.025 * 480 - Fee = 12 GBP 3. Add the minimum fee to the calculated fee: - Minimum fee = GBP 3 - Total fee = 12 + 3 - Total fee = 15 GBP Answer: 15 GBP
For arithmetic that matters, call a function. Let the model pick the rule and the inputs, and let code do the multiplication.

Adaptation · Concept

Concept Three ways to make a general model do the bank’s task. They differ in what is trained and in what has to be stored and served afterwards.

red: trained on the bank’s data

Prompting

Nothing is trained. One copy of the model serves every task. Behaviour is changed by editing text, and is limited to what the model can already do.

LoRA

The model is frozen and a small set of new weights is trained beside it. One base model in memory, one small adapter file per task.

Full fine-tuning

All weights are updated. The result is a complete second model, to be stored, versioned and served on its own.

LoRA · Intuition

Intuition A weight matrix W is left alone. The change to it is written as the product of two thin matrices, B and A, and only those are trained.

one attention matrix of DistilBERT

1. Two thin matrices

B has r columns and A has r rows. Their product BA has the shape of W, so it can be added to it.

2. The rank r

r sets the size. At r = 8 the two matrices hold 12,288 weights where W holds 589,824.

3. Across the model

The same pair is added beside the query and value matrices of every attention layer. Everything else keeps the weights it was downloaded with.

LoRA · Mechanism

Mechanism The layer computes its usual output and adds the output of the two thin matrices, scaled.

h  =  W x  +  (α / r) · B A x
symbolwhat it is
Wthe downloaded weight matrix, frozen
xthe input to the layer
Ar × d matrix, starts as small random numbers
Bd × r matrix, starts as zeros
rthe rank: 1 to 64 in practice
αa fixed scale, often 2r
B starts at zero, so BA is zero and the adapted model begins exactly as the downloaded one.

After training. Either keep the adapter as a separate file and load it over the base model, or add BA into W once and serve a model with no extra cost per request.
Why it works. Adapting to one task moves the weights in few directions. A low-rank matrix can hold those directions.
